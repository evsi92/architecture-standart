### <a name="_qmphm5d6rvi3"></a>**Решение**
В силу необходимости максимально переиспользовать уже существующий стек технологий и компоненты, принято решение:
- обновить имеющиеся приложение сайта и сделать в нем новый функционал для просмотра доступных депозитных возможностей, а также поддержать возможность создания заявки на депозит
- сайт должен быть интегрирован с кафка для дальнейших расширений
- обновить стек текущего приложения банка для его возможности интеграции с кафка
- приложение должно быть расширено для поддержки просмотра общих депозитных предложений, персонализированных предложений; возможность оставить заявку и открыть депозит
- необходимо создать новый микросервис, который будет собирать текущие предложения по депозитам и персонализированные. Он должен защищено предоставлять эти данных по api требуемым системам
- необходим новый временный микросервис для трансформации полученных кафка сообщений от клиентов банка в апи запрос к абс. Этот сервис будет обрабатывать сообщения с регулируемой скоростью, чтобы избежать перегрузки АБС
- новый смс-шлюз для интеграции с сайтом и приложением 
- минимальные изменения на абс на время mvp: тк в рамках mvp всю обработку заявок по-прежнему осуществляют сотрудники бэк-офиса, принято решение не вносить существенных изменений в абс на данном этапе
- однако необходимо, чтобы абс начал отправлять сообщения о проведенных операциях в кафка топик для наполнения данными новый микросервис
- все приложения, которые создаются с нуля или подвергаются существенному апгрейду, должны также переехать в кубернейтис
### <a name="_bjrr7veeh80c"></a>**Альтернативы**
- рассматривался вариант перестроить / разбить на микросервисы АБС на данном этапе. Но в силу ограничения ресурсов и времени, сосредоточились на новых функциональностях, которые не требуют изменений в АБС
- исключен вариант прямого вызова АБС из приложения или сайта для регулировки нагрузки. На данном этапе рассмотрение заявки происходит сотрудником Бэк-офиса, поэтому распределение нагрузки с помощью очереди не будет негативно влиять на пользователя

**Недостатки, ограничения, риски**
АБС на данном этапе все еще не масштабирован, что может влиять на скорость обработки заявок бэк-офисом
Большее количество имплементационных работ будет сосредоточено в IT командах банка
